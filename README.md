## Captions

**Same zoo, new engine:** Same zoo. Same lion. New engine. RustyZoo is an open-source reimplementation of Zoo Tycoon (2001), written in Rust, that runs your own copy of the game on Windows, macOS and Linux, checked against the original picture against picture. Pre-alpha, built milestone by milestone, and every step is in the gallery: https://rustyzoo.com

**The manual:** Spot the difference: one side is Zoo Tycoon (2001), the other is RustyZoo, an open-source engine written in Rust that runs your own copy of the game on Windows, macOS and Linux. Pre-alpha and not playable yet, but every step is dated in the gallery: https://rustyzoo.com

**Promo (30 s):** Remember this? Zoo Tycoon (2001), now on RustyZoo, an open-source engine written in Rust. Free play works today if you build it from source; saving games, research, scenarios and awards are on the way. Bring your own copy of the game (full game or free trial). Pre-alpha, GPL-3.0, Windows, macOS and Linux: https://rustyzoo.com

The pictures come from the public [screenshots](https://github.com/RustyZoo/screenshots) gallery and the website; the music is synthesized.

**Promo credits:** pictures from the public screenshots gallery (the original game and RustyZoo), animal calls from the original game. Zoo Tycoon logo, graphics and sounds (c) Microsoft; RustyZoo is not affiliated with Microsoft.

**How the promo was made:** each scene is an HTML page in the website's style, rendered frame by frame with Playwright and encoded with ffmpeg.
The music is synthesized in Python with numpy at 128 BPM, timed to the cuts.
